# sk8 — スケボースクール連絡帳

保護者さまとやりとりするWeb連絡帳です。書いた連絡帳は全部Googleスプレッドシートに残り、保護者さまは**生徒さんごとの専用リンク**で、これまでの記録をいつでも見返せます。

## 全体の流れ

```
【コーチ】coach.html で書いて「保存する」
      ↓（自動でスプレッドシートに1行追加）
【スプレッドシート】連絡帳・既読・メッセージが全部たまっていく
      ↑↓
【保護者さま】専用リンク（いつも同じ）を開く
   → 最新の連絡帳・これまでの連絡帳・技の成長が見られる
   →「読みました」を押す／質問・メッセージを送る
```

| ファイル | 役割 |
| --- | --- |
| `index.html` | 保護者さまが見るページ |
| `coach.html` | コーチ用ページ（生徒登録・連絡帳を書く・既読とメッセージの確認） |
| `config.js` | 予約URL・Instagram・LINE・スプレッドシートのURLの設定 |
| `gas/Code.gs` | スプレッドシートにデータを保存するプログラム |

## ふだんの使い方

**新しい生徒さんが来たとき（1回だけ）**
1. `coach.html` の「生徒さん」で名前を登録する
2. 表示された「専用リンクのご案内」をコピーし、保護者さまにLINEで送る

**レッスンのたび**
1. `coach.html` の「連絡帳を書く」で生徒さんを選ぶ（何回目かは自動で入ります）
2. 書いて「保存する」
3. 表示された「連絡帳が届きました」の文をコピーし、LINEで送る
4. 「既読・メッセージ」で、既読か未読か、保護者さまからのメッセージを確認する

書いた後で直したいときは、スプレッドシートの「連絡帳」シートで文章を書き換えると、保護者さまのページにもそのまま反映されます。

## 最初の設定

### 1. スプレッドシートとプログラム
1. Googleスプレッドシートを新しく作る（名前は「スケボー連絡帳」など）
2. メニュー「拡張機能」→「Apps Script」
3. 最初から入っている文字を全部消して、`gas/Code.gs` の中身を全部貼り付けて保存（💾）
4. **合言葉を作る**：左の歯車 ⚙️「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ：`ADMIN_KEY`
   - 値：好きな合言葉（例：`cocco2026skate`）
   - 「スクリプト プロパティを保存」
5. 右上の「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押す
6. 許可を求められたら、次の順に進む（自分で作ったプログラムなので安全です）
   - 「アクセスを承認」→ 自分のアカウントを選ぶ
   - 「Google hasn't verified this app」→「Go to 〇〇 (unsafe)」
     （出ていなければ、左下の「Advanced / 詳細」を押すと出てきます）
   - 「Continue / 許可」
7. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピーする

### 2. config.js にURLを入れる
`config.js` の `gasUrl: ""` の `""` の中に、7 のURLを貼り付ける。

### 3. ページを公開（GitHub Pages）
GitHub のリポジトリ →「Settings」→「Pages」→ Branch で公開するブランチと `/ (root)` を選んで Save。
数分後に `https://<ユーザー名>.github.io/sk8/coach.html` で開けるようになります。最初に合言葉を入れれば、次からは自動で開きます。

### 4. 次回予約のリンク
予約ページのURLが決まったら、`config.js` の `reserveUrl` に貼り付ける。空の間は「準備中」と表示されます。

## プログラム（Code.gs）を更新するとき
URLを変えずに更新するには、Apps Script で中身を貼り替えて保存した後、
「デプロイ」→「デプロイを管理」→ 鉛筆マーク ✏️ →「バージョン」を **新しいバージョン** にして「デプロイ」。
（「新しいデプロイ」にするとURLが変わってしまうので、その場合は `config.js` も書き換えてください）

## 安全のために
- 保護者さまの専用リンクには推測できない長いIDが入っているので、他の生徒さんの連絡帳は見られません。リンクはご家族以外に共有しないようお伝えください。
- 全員分の一覧は、合言葉を知っている人しか見られません。
- スプレッドシートはあなたのGoogleアカウントの中にだけあります。
