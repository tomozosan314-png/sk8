# sk8 — スケボースクール連絡帳

生徒さん（保護者さま）向けのWeb連絡帳です。

| ページ | 用途 |
| --- | --- |
| `index.html` | 保護者さまが見るページ（フィードバック、日付・時間・何回目、既読ボタン、メッセージ、次回予約・Instagram・公式LINE） |
| `coach.html` | コーチが書くページ。入力すると保護者さまに送るリンクができます。既読とメッセージの一覧も見られます |
| `config.js` | 予約URL・Instagram・LINE・Apps Script のURLの設定 |
| `gas/Code.gs` | 既読とメッセージをGoogleスプレッドシートに記録するプログラム |

## 使い方（毎回）
1. `coach.html` を開いて、生徒さんの名前・日付・時間・何回目・フィードバックなどを入力
2. 「リンクを作成」→「リンクをコピー」して、公式LINEなどで保護者さまに送る
3. 保護者さまが「読みました」を押すと、スプレッドシートの「既読」シートに記録されます
4. `coach.html` の「最新の状況を見る」で、既読・未読とメッセージを確認できます

## 最初の設定（1回だけ）

### 1. GitHub Pages で公開
GitHub のリポジトリ → Settings → Pages → Branch を `main`（または公開したいブランチ）/ root にして Save。
`https://<ユーザー名>.github.io/sk8/coach.html` で開けるようになります。

### 2. 既読・メッセージの受け取り（Google スプレッドシート）
1. Googleスプレッドシートを新規作成
2. メニュー「拡張機能 → Apps Script」を開き、`gas/Code.gs` の中身を貼り付けて保存
3. 左の歯車「プロジェクトの設定」→「スクリプト プロパティ」に `ADMIN_KEY` を追加（値は好きな合言葉）
4. 右上「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示されたURL（`https://script.google.com/macros/s/.../exec`）を `config.js` の `gasUrl` に貼り付け
6. `coach.html` の「管理キー」に、3 で決めた合言葉を入力

### 3. 次回予約リンク
予約ページのURLが決まったら `config.js` の `reserveUrl` に貼り付けてください。空の間は「準備中」と表示されます。

## メモ
- 連絡帳の内容はリンクの中に入っています（サーバーには保存されません）。リンクを知っている人だけが見られます。
- 既読・メッセージはスプレッドシートに記録されます。管理キーを知らない人は一覧を見られません。
