Apps Script のコード

1. コードをコピー

2. Apps Script に貼り付けて保存

  1. Apps Script のコードの中を1回クリック
  2. Ctrl + A（Mac は ⌘ + A）で全部選ぶ
  3. Delete で消す
  4. Ctrl + V（Mac は ⌘ + V）で貼り付け
  5. Ctrl + S（Mac は ⌘ + S）か 💾 で保存
  6. 確認：12行目あたりに「各シートは1行目の見出し」と書いてあればOK

3. 公開し直す

  1. 上の関数の選択欄で testNotify を選んで「▶ 実行」（初回は許可の画面が出ます。テストメールが届けばOK）
  2. 「デプロイ」→「デプロイを管理」→ 鉛筆マーク ✏️
  3. 「バージョン」で 新バージョン を選んで「デプロイ」
  4. コーチ用ページを開き直して、黄色い警告が消えていれば完了
